Assets.java и AssetScaler.java
В данных файлах происходит управление ресурсами.

Assets.java определяет местоположение графических элементов, звуковых файлов и музыкальных композиций. С помощью этого кода программа записывает данные в оперативную память при запуске и удаляет их после завершения работы.

AssetScaler.java выполняет функции по изменению размеров графики. В нем прописаны условия, по которым изображения масштабируются в соответствии с разрешением дисплея. Это необходимо, чтобы визуальные элементы отображались без искажений.

GameState.java
В этом компоненте хранятся текущие параметры игрового процесса.

В GameState.java содержатся числовые значения, которые отражают текущее количество единиц и общее количество за весь период.

С помощью данного кода система отслеживает временные интервалы. Это нужно, чтобы начислять автоматический доход и определять моменты появления объекта GoldenCookie.

Здесь выполняются вычислительные операции. К ним относятся расчет увеличения стоимости объектов и алгоритм работы функции Престиж, которая обнуляет прогресс для получения преимуществ.

3. Milestone, GoldenCookie и другие элементы
Из этих компонентов формируется структура программы.

Building.java содержит характеристики объектов, таких как Курсоры, Бабушки или Шахты. Для каждого из них установлена цена и показатель производительности.

Milestone.java отвечает за систему достижений. Если выполняется заданное условие, программа фиксирует получение награды.

GoldenCookie.java управляет объектом, который появляется на экране на ограниченное время. В коде прописан таймер, по истечении которого элемент удаляется, если действие не было совершено.

FloatingText и Particle используются для отображения графических эффектов. К ним относятся числовые значения "+5" и мелкие элементы, которые перемещаются по экрану при нажатии.

Renderer.java и InputHandler.java
Через эти инструменты осуществляется взаимодействие пользователя с системой.

Renderer.java отображает информацию на экране. С частотой 60 раз в секунду он извлекает данные из GameState.java и преобразует их в визуальные образы. Но он не выполняет расчеты количества ресурсов.
